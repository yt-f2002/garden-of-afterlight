Project notes & credits

Garden of Afterlight
Browser demonstrations, 2026.

Two experiences

The Blank Signature presents the existing story, investigation, spirit defence and dressmaking systems through the main game interface. Its dressmaking workbench uses a 3D mannequin.

The Cloud Courtyard presents the existing first-person environment exploration prototype. It is shared as a work in progress; dedicated 3D gameplay is not yet implemented.

Creative work

The project uses an AI-assisted workflow for code and visual asset development. The artwork and models shown here are supplied by the Garden of Afterlight project.

Technology

Built with Godot Engine 4.7.2. Godot is distributed under the MIT licence. Browser editions use WebAssembly and WebGL 2.0.

Browser edition

The original desktop projects are preserved. These separate publishing copies use web export settings, a lighter version of the same opening film, and a browser start screen. The 3D entry follows the supplied desktop shortcut’s first-person launch behaviour.

Save data is stored locally in your browser. No account is required. Clearing site data removes that browser’s saved progress.
